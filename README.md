# MDX Firmware

Extended firmware for the Elektron Machinedrum. Created by Yatao Li and Justin Mammarella.

MDX is independently developed with permission from Elektron. Please direct MDX support requests and bug reports to this repository’s [issue tracker](https://github.com/jmamma/MDX/issues) or [Discord](https://discord.gg/XVasxjw36e).
